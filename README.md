# Chiyalaya · चियालय

A simple, responsive Nepali-inspired restaurant collection built with React and Vite.

Live website: https://chiyalaya.vercel.app

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Project structure

- `src/main.jsx`: React entry point.
- `src/App.jsx`: Page layout.
- `src/components/`: Header, hero, restaurant cards, badges, ratings, and footer.
- `src/data/restaurants.js`: Six fictional restaurant profiles.
- `src/style.css`: Responsive styles.

Restaurants and ratings are illustrative. Food photographs are hosted by Unsplash; fonts are hosted by Google Fonts.
